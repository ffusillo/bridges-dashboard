# BRIDgeS – public dashboard

The built website of the BRIDgeS project (University of Turin): research and
innovation on sustainable plastics, from publications (OpenAlex) and patents
(PATSTAT). Published with GitHub Pages at
https://ffusillo.github.io/bridges-dashboard/

**Provisional results:** the corpora are being validated; every number may change.

This repository holds only the generated site (HTML and aggregated tables).
