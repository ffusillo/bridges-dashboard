Maps

Interactive maps of knowledge and of collaboration

Provisional results. The corpora are being validated: every number may change.

The maps open in VOSviewer Online, the web version of VOSviewer, a tool widely used to draw maps of science. In a map, each circle is a topic, a technology, a country or an organisation; its size is the number of documents; a line joins two circles that appear together in the same documents. Circles close to each other are strongly linked, and circles of the same colour form a group (a cluster). Zoom with the mouse wheel, drag to move, and click on a circle to see its details.

mapsList = [

viewof chosen = Inputs.select(mapsList, {label: "Map", format: d => d.name, value: mapsList[0]})
jsonUrl = new URL(`data/maps/${chosen.file}.json`, document.baseURI).href
// NB the address must NOT be encoded (encodeURIComponent): VOSviewer Online
// then fails to read the file (checked on 25 Nov 2026)
vosUrl = `https://app.vosviewer.com/?json=${jsonUrl}&simple_ui=true`
online = !["localhost", "127.0.0.1"].includes(location.hostname)
html`<p>${chosen.text}
  <a href="${vosUrl}" target="_blank" rel="noopener">Open full screen</a> ·
  <a href="${jsonUrl}" download>Download the map file</a></p>
  ${online ? html`<iframe class="vos-frame" allowfullscreen="true" src="${vosUrl}"></iframe>`
           : html`<p class="provisional">The maps are shown only when the website is online
                  (VOSviewer Online cannot read files from this computer).</p>`}`
